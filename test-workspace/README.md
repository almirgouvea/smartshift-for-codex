# SmartShift test folder

The window opened with **F5** uses this folder. Ask Codex anything here without touching the extension's code.

Requests to try each tier:

- Simple: `explain what the soma function does`
- Medium: `implement a media(list) function in calc.js with tests`
- Complex: `redesign the architecture of calc.js to support operation plugins and migrate the existing functions`

## Pasta de teste do SmartShift

A janela aberta pelo **F5** usa esta pasta. Peça ao Codex o que quiser aqui sem risco para o código da extensão.

Pedidos para testar cada nível:

- Simples: `explique o que a função soma faz`
- Média: `implemente uma função media(lista) em calc.js com testes`
- Complexa: `redesenhe a arquitetura de calc.js para suportar plugins de operações e migre as funções existentes`
